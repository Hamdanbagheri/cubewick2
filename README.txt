CUBEWICK WEBSITE + GAME FOLDER
==============================

Open index.html to view the classic-style CUBEWICK website.
The uncompressed CUBEWICK_Player_Folder directory is inside this website folder.
The site's Download CUBEWICK button downloads CUBEWICK_Player_Folder.zip.

Avatar color connection:
- Build Developer Source/CUBEWICK_Web_Avatar_Color.cpp into your CUBEWICK EXE.
- Start that rebuilt game, then open index.html on the same PC.
- Sign in to the browser-local demo account, choose My CUBEWICK, and change Avatar Color.
- The website sends the RGB values over the local bridge on 127.0.0.1:47821.

The real compiled EXE was not among the supplied files, so it is not included.
The game folder cannot launch until that EXE and any required runtime DLLs are added.
For a public hosted website, remote account sync requires a real backend.
