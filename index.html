Parents

Information about the CUBEWICK project.

What is CUBEWICK?

CUBEWICK is an independent single-player game project inspired by classic block-building games. This prototype site does not process payments or collect information on a public server.

Privacy note

The demo account data and forum posts are stored in your browser's local storage on this device. Clearing browser storage removes them.

Help

Frequently asked questions.

How do I create an account?

Press Sign Up, choose a username and password, then submit the form.

Can other people log in to this account?

Not yet. The demo account is saved in this browser only. Public accounts need a secure server and database.

Can the website change my avatar?

The connected desktop build listens on this PC for avatar color changes from the website. Start the game, sign in to the local profile, then use Avatar Appearance.

Can I launch the game from this site?

The desktop EXE download and launch flow haven't been connected yet.
